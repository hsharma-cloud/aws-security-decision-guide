# Security Monitoring and Threat Detection

## Overview

Security Monitoring and Threat Detection provide the visibility required to secure AWS environments. Organizations must continuously monitor their cloud infrastructure, detect abnormal behavior, identify vulnerabilities, and respond to security events before they become incidents.

AWS offers a comprehensive ecosystem of security services that work together to collect logs, monitor resource activity, detect threats, assess vulnerabilities, and automate security operations. Rather than viewing each service independently, security professionals should understand how they complement one another to provide centralized visibility, continuous monitoring, threat detection, compliance assessment, and incident response.
