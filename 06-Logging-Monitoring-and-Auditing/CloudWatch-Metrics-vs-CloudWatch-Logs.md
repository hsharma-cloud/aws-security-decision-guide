# CloudWatch Metrics vs CloudWatch Logs

## Purpose

Amazon CloudWatch Metrics and CloudWatch Logs are core components of Amazon CloudWatch, but they serve different purposes. CloudWatch Metrics collect numerical performance data from AWS resources and applications over time, while CloudWatch Logs collect, store, and analyze log data generated by applications, operating systems, and AWS services. Together, they provide comprehensive operational visibility into AWS environments.

| Feature | CloudWatch Metrics | CloudWatch Logs |
|---------|--------------------|-----------------|
| Primary Purpose | Monitor Numerical Performance Data | Collect and Analyze Log Data |
| Data Type | Time-Series Metrics | Log Events |
| Examples | CPU Utilization, Network In/Out | Application Logs, System Logs |
| Supports Alarms | Yes | Indirectly (Metric Filters) |
| Visualization | Dashboards and Graphs | Log Insights and Dashboards |
| Log Storage | No | Yes |
| Historical Analysis | Yes | Yes |
| Best For | Performance Monitoring | Troubleshooting and Log Analysis |
| Typical Users | Operations Teams | Operations and Security Teams |

## Key Differences

- CloudWatch Metrics store **numerical time-series data**.
- CloudWatch Logs store **text-based log events**.
- Metrics are ideal for monitoring performance trends.
- Logs provide detailed diagnostic information for troubleshooting.
- Metric Filters can convert log patterns into metrics for alerting.

## When to Choose CloudWatch Metrics

Use CloudWatch Metrics when you need to:

- Monitor CPU utilization.
- Track memory or network performance.
- Create alarms.
- Build dashboards.
- Monitor service health over time.

## When to Choose CloudWatch Logs

Use CloudWatch Logs when you need to:

- Troubleshoot application issues.
- Analyze system logs.
- Search log events.
- Store application and infrastructure logs.
- Perform log analytics with CloudWatch Logs Insights.

## Quick Decision

| If you need to... | Choose |
|-------------------|--------|
| Monitor EC2 CPU utilization | **CloudWatch Metrics** |
| Search Lambda execution logs | **CloudWatch Logs** |
| Trigger an alarm when memory usage is high | **CloudWatch Metrics** |
| Investigate an application error | **CloudWatch Logs** |
| Build performance dashboards | **CloudWatch Metrics** |
| Analyze detailed log messages | **CloudWatch Logs** |
