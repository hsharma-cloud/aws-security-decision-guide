# Infrastructure and Network Security

## Overview

Infrastructure and Network Security protect AWS workloads by controlling connectivity, isolating resources, inspecting traffic, and defending applications against network-based attacks. A well-designed AWS network architecture minimizes the attack surface while ensuring secure, scalable, and highly available communication between services, users, and external networks.

AWS provides a comprehensive portfolio of networking and security services, including Amazon VPC, Security Groups, Network ACLs, AWS Network Firewall, AWS WAF, AWS Shield, AWS Transit Gateway, AWS Cloud WAN, AWS PrivateLink, VPC Endpoints, VPN, Direct Connect, NAT Gateway, Internet Gateway, Elastic Load Balancing, AWS Global Accelerator, Gateway Load Balancer, and AWS Systems Manager Session Manager.

Rather than selecting services independently, architects and security engineers should understand how these services complement one another to build secure, resilient, and scalable network architectures.
