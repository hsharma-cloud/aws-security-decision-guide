# Identity & Access Management

> **Section 4 | AWS Certified Security – Specialty (SCS-C03)**

---

## Overview

Identity is the foundation of AWS security.

This section focuses on authentication, authorization, permissions, federation, temporary credentials, and the principle of least privilege.

Rather than simply explaining AWS services, this section helps you understand **when to use one identity solution instead of another** through practical comparisons and real-world scenarios.

---

This section covers the following AWS Identity and Access Management topics:

- AWS Root User
- IAM Users
- IAM Groups
- IAM Roles
- IAM Policies
- Resource-Based Policies
- Service Control Policies (SCPs)
- AWS Organizations
- AWS IAM Identity Center

- Amazon Cognito
- Federation
- Cross-Account Access
- Temporary Credentials
- Multi-Factor Authentication (MFA)
- Least Privilege
- Permission Boundaries
- IAM Access Analyzer
