# Infrastructure and Network Security

## Overview

Infrastructure and Network Security establish the protective foundation of AWS environments by securing compute resources, networks, and communication paths. A well-designed security architecture applies defense-in-depth principles to reduce the attack surface, enforce least privilege, and protect workloads from unauthorized access and network-based threats.

AWS provides a comprehensive portfolio of networking and infrastructure security services, including Amazon VPC, Security Groups, Network ACLs, AWS Network Firewall, AWS WAF, AWS Shield, AWS Transit Gateway, AWS PrivateLink, VPC Endpoints, AWS Direct Connect, AWS VPN, Elastic Load Balancing, Route 53 Resolver DNS Firewall, and AWS Firewall Manager. These services work together to create secure, scalable, and resilient cloud architectures.

This section explores the purpose of each networking and infrastructure security service, explains how they interact within AWS architectures, and provides guidance for selecting the appropriate service based on security, availability, performance, and operational requirements.

By understanding AWS networking fundamentals and infrastructure security controls, readers will be able to design secure cloud environments, protect workloads from common threats, and implement network architectures that support modern enterprise security requirements.
